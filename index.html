How this works

  1. A listener taps WhatsApp or Telegram on this page and sends the link to a friend or group.
  2. The chat shows a small preview card (below).
  3. Whoever taps it sees this page in their phone's browser. No app to install, no account.
  4. They press play to stream the audio, or tap Download to keep the MP3 and listen later without internet.

The preview card in a chat

Chat apps build this card from tags in the page head. The image is a 1200 × 630 JPEG, 30 KB.

What is real and what is placeholder

  • The program name, episode title and description come from the TWR360 page for this program in Nepali. The description is cut at the same point as on that page.
  • The share buttons send the TWR360 program link. In production they would send the address of this lightweight page.
  • The audio is a 6-second test tone. In production it plays from a file on the CDN, with an Opus version first and an MP3 fallback.
  • The Nepali button text is placeholder wording for a native speaker to check.
